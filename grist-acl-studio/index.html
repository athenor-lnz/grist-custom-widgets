ACL actuelles du document

Vue technique fidèle aux tables internes _grist_ACLResources et _grist_ACLRules.

1. Demander les règles à une IA

Le prompt contient la structure du document et les ACL, jamais les données métier.

Workflow conseillé
  1. Décris le besoin.
  2. Copie le prompt dans ChatGPT, Claude ou Gandalf.
  3. Demande une réponse JSON uniquement.
  4. Colle le JSON à droite puis valide.

2. Importer le JSON proposé

Le widget vérifie tables, colonnes, permissions, présence d’une règle Owner et doublons.

Aucun JSON chargé.

Simulation avant application

Seules les ressources présentes dans le JSON sont remplacées. Les autres ressources ACL restent intactes.

Valide d’abord un JSON pour voir les changements.
